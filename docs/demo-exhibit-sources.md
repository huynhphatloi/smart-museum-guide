# Demo exhibit images and sources

The demo catalogue has 20 published examples with images: four original visitor-journey objects and 16 additional Vietnamese works from The Met's Open Access collection. There is also one unpublished textile draft. These are **not** a claim that the objects belong to the museum deploying this app. A museum must replace the demo records with its own catalogue data and approve visitor copy before public launch.

Images were downloaded at web display resolution. The seeded descriptions use only claims supported by the linked records or directly visible in the image. Image captions in the visitor UI include the source and rights label.

The short descriptions are one-line introductions. The full `description` field contains an original, multi-paragraph Vietnamese visitor reading script. Context in the first four scripts was checked against [UNESCO's Mỹ Sơn overview](https://whc.unesco.org/en/list/949/), the [Vietnam National Museum of History on Đông Sơn](https://baotanglichsu.vn/VI/Articles/4002/68892/trung-bay-chuyen-dje-van-hoa-djong-son.html), its [article on Ngũ Hổ painting](https://baotanglichsu.vn/fr/Articles/3269/72860/limage-du-tigre-dans-lestampe-populaire-de-hang-trong.html), and [The Met's elephant dish record](https://www.metmuseum.org/art/collection/search/40001). The new 16 scripts use the linked Met records and visible features; uncertain object-specific details are clearly qualified.

The seed stores **Vietnamese only** (`vi`) as original copy. Neither translated text nor narration audio is bundled for the 20 published records. The Admin localization action sends the saved Vietnamese copy to the configured AI service; its returned translations and TTS audio are stored as generated results.

The old 1.8-second sample audio clips were removed. Narration stays unavailable until genuine audio is produced and reviewed. The seed script replaces demo database records when run, so it must not be used against a database with real content.

For an **existing local database**, run `npm run db:seed-collection` from `backend/` to preview, then `npm run db:seed-collection -- --apply` to add only the missing 16 sourced exhibits. The incremental script checks for code and image collisions, preserves staff, zones and assignments, and removes the six exact, unedited manual translations from the first four demo records. Edited or AI-produced translations are left in place. It is disabled in production.

For an existing local demo database, `backend/api/prisma/refresh-demo.ts` validates the four original demo records, supports a dry run, and updates only their content plus the B01 zone name. It preserves staff accounts, beacons, and assignments. Run from `backend/api` with `../node_modules/.bin/ts-node --transpile-only -r dotenv/config prisma/refresh-demo.ts` first, then add `--apply` after reviewing the result. It refuses to run when `NODE_ENV=production`.

After the sourced demo images are installed, `backend/api/prisma/refresh-demo-narration.ts` can expand the first short demo descriptions into the reading scripts. It checks the original copy before writing and refuses to overwrite edited translations. Run it from `backend/api` with `../node_modules/.bin/ts-node --transpile-only -r dotenv/config prisma/refresh-demo-narration.ts` for a dry run, then add `--apply`. It is also disabled in production.
